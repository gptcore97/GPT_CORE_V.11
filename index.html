# GPT CORE 11.0 — Multi-AI Terminal Assistant Welcome to the official repository of **GPT CORE 11.0**, developed by Flubatir. This tool allows you to centralize and run multiple AI engines both Cloud and completely Offline directly from your terminal interface. ### 🚀 Key Features * **DeepSeek V4 Flash**: Ultra-fast Cloud processing via OpenRouter. * **Qwen Coder 2.5-7B (Local)**: Specialized model for coding tasks and image processing (Vision). * **Llama 3.2-3B (Local)**: Fast and lightweight responses without internet connection. * **DreamShaper 8**: Local Stable Diffusion image generator (512x512). * **Script Automation**: Automatically stores generated code inside the `programmi/` folder. * **Attachment System**: Real-time monitoring of the `Allegati/` directory. ### 📦 Installation Guide 1. Download the core archive (`Gpt-Core-V.11_En.rar`) and extract it locally. 2. For offline capabilities, download the model package `Intelligences Artificial.rar` and engine runtimes `Motor A.I.rar`. 3. Configure your local paths and OpenRouter API key inside the generated `config.json` file. 4. Launch the executable or run the `.py` main file from your terminal.
